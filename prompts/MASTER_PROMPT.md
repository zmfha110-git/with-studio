# MASTER PROMPT

Version: 1.0  
Status: Active

첫 번째 이미지를 마스터 레퍼런스로 사용해.

첫 번째 이미지에서는 아래 촬영 요소만 참고해.

- 배경
- 조명
- 그림자
- 노출
- 화이트밸런스
- 색감
- 박스 표면의 촬영 질감

첫 번째 이미지의 박스 형태나 비율은 따라 하지 마.

두 번째 이미지는 실제 제품 원본이야. 새로운 박스를 생성하거나 다시 디자인하지 말고, 기존 제품 사진을 전문적으로 리터칭하는 작업으로 처리해.

두 번째 이미지에서 아래 요소는 그대로 유지해.

- 원본 박스의 가로세로 비율
- 실제 폭과 높이 관계
- 외곽 실루엣
- 접힘 구조와 모서리 위치
- 로고
- 모든 한글 텍스트
- 글자 크기와 굵기
- 자간과 행간
- 인쇄 위치
- 디자인 레이아웃

촬영각은 레퍼런스처럼 거의 정면으로 보이도록 최소한의 수평·수직 원근 보정만 적용해. 박스를 3D로 회전하거나 폭과 높이를 늘이거나 줄이지 마.

최종 이미지는 다음 기준으로 보정해.

- 순백에 가까운 심리스 스튜디오 배경
- 부드러운 하이키 확산광
- 박스 아래의 아주 약하고 자연스러운 접지 그림자
- 밝은 웜 베이지 크라프트 톤
- 매우 매끄러운 고급 무광 종이 표면
- 골판 무늬, 세로 결, 주름, 얼룩, 먼지와 오염 제거
- 중앙 배치
- 여백이 충분한 1:1 정사각형 캔버스
- 상업용 제품 카탈로그 수준의 깨끗한 결과

레퍼런스 스타일과 원본 형태 유지가 충돌하면 항상 원본 박스의 형태, 비율, 글자와 디자인 유지를 우선해.

최종 결과는 새로운 박스를 만든 이미지가 아니라, 원본 박스를 레퍼런스와 같은 스튜디오에서 다시 촬영하고 전문적으로 리터칭한 사진처럼 보여야 해.
