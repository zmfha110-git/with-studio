# QA Checklist

결과물 1건마다 원본을 나란히 놓고 확인합니다. `필수` 항목 하나라도 실패하면 다른 항목의 완성도와 관계없이 최종 판정은 `FAIL`입니다.

## 1. 실행 조건

- [ ] 마스터 레퍼런스를 첫 번째 이미지로 사용함
- [ ] 해당 제품의 `original` 파일을 두 번째 이미지로 사용함
- [ ] 사용 프롬프트와 버전을 확인함
- [ ] 원본·결과 파일 경로를 기록함

## 2. 원본 보존 — 필수

- [ ] 박스 가로세로 비율이 원본과 동일함
- [ ] 실제 폭과 높이 관계가 유지됨
- [ ] 외곽 실루엣이 유지됨
- [ ] 접힘 구조와 모서리 위치가 유지됨
- [ ] 로고의 형태·색상·위치가 유지됨
- [ ] 모든 한글 텍스트의 내용이 유지됨
- [ ] 글자 크기·폭·굵기·자간·행간이 유지됨
- [ ] 인쇄 위치와 디자인 레이아웃이 유지됨
- [ ] 새 요소가 생성되거나 기존 요소가 사라지지 않음

## 3. 카메라와 배치

- [ ] 거의 정면이며 카메라와 박스 전면이 평행함
- [ ] 수평·수직 원근 보정이 최소 범위임
- [ ] 3D 회전이나 폭·높이 변형이 없음
- [ ] 1:1 캔버스 중앙에 배치됨
- [ ] 제품 주변 여백이 충분함

## 4. 배경·조명·그림자

- [ ] 배경이 경계·소품·반사·질감 없는 순백에 가까움
- [ ] 조명이 부드러운 하이키 확산광임
- [ ] 노출과 화이트밸런스가 중립적임
- [ ] 과한 하이라이트나 누런 색조가 없음
- [ ] 박스 아래에 옅고 자연스러운 접지 그림자만 있음
- [ ] 제품이 떠 보이거나 그림자가 진하고 길지 않음

## 5. 표면과 마감

- [ ] 밝은 웜 베이지 크라프트 톤임
- [ ] 매끄러운 고급 무광 표면으로 보임
- [ ] 종이 질감은 미세하고 불규칙함
- [ ] 골판 무늬·세로 결·주름·얼룩·먼지·오염이 없음
- [ ] 과한 광택이나 인위적인 플라스틱 질감이 없음
- [ ] 가장자리와 텍스트 주변에 생성 흔적이 없음

## 6. 최종 판정

- [ ] `PASS`: 모든 필수 항목과 스타일 기준 충족
- [ ] `REVISE`: 필수 항목은 통과했으나 스타일·마감 수정 필요
- [ ] `FAIL`: 필수 항목 중 하나 이상 실패

판정과 근거는 `tests/TEST_LOG.md`에 기록합니다.
