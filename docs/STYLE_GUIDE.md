# WITH Product Photo Style Guide

## 1. Canvas

- 비율: 1:1
- 제품 중앙 배치
- 제품 주변에 충분한 흰색 여백
- 제품별 실제 비율 유지
- 제품 크기를 레퍼런스 박스 크기에 억지로 맞추지 않음

## 2. Camera

- 거의 완전한 정면 촬영
- 카메라와 박스 전면이 평행
- 카메라 높이는 박스 정면 중앙
- 왜곡이 적은 제품 촬영 렌즈 느낌
- 최소한의 수평·수직 원근 보정만 허용
- 박스의 폭과 높이 변경 금지

## 3. Background

- 순백에 가까운 심리스 배경
- 기준 색상: `#FFFFFF`
- 배경 경계선 없음
- 소품 없음
- 반사 없음
- 배경 질감 없음

## 4. Lighting

- 하이키 스튜디오 조명
- 부드러운 확산광
- 정면 중심의 균일한 조명
- 낮은 대비
- 과한 하이라이트 없음
- 누렇게 뜨는 색조 없음

## 5. Shadow

- 박스 아래의 자연스러운 접지 그림자만 사용
- 매우 부드럽고 옅게 표현
- 제품이 떠 보이지 않게 함
- 진하고 길게 뻗는 그림자 금지

## 6. Kraft Surface

- 밝은 웜 베이지 크라프트 톤
- 고급 무광 표면
- 전체적으로 매끄러운 재질
- 아주 미세하고 불규칙한 종이 질감
- 골판 무늬 없음
- 세로 결 없음
- 주름, 얼룩, 먼지, 오염 없음
- 과한 광택 없음

## 7. Locked Elements

다음 요소는 원본을 그대로 유지합니다.

- 박스 가로세로 비율
- 외곽 실루엣
- 접힘 구조
- 로고
- 모든 한글 텍스트
- 글자 크기
- 글자 폭과 굵기
- 자간과 행간
- 인쇄 위치
- 디자인 레이아웃

## 8. Priority

충돌이 발생하면 아래 순서를 따릅니다.

1. 원본 박스 형태 유지
2. 원본 텍스트와 로고 유지
3. 원본 디자인 배치 유지
4. 레퍼런스의 촬영 스타일 적용
